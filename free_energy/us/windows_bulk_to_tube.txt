# US 窗口清单：每行 "窗口中心z 弹簧常数k"
#
# ============================================================
#  方案（宽量程版）：管外体相一直算到管内，共 47 个窗口
#  体相区 k=10 + 大间距；孔区 k=250 + 小间距
#  生成规则：管外体相 12..5(步长1,k=10)；孔区 4.5..-4.5(步长0.25,k=250)；管内 -5..-6(步长1,k=10)
# ============================================================
#
# 什么时候用这个方案：
#   需要「从体相到管内」的**绝对** PMF（而不是相对某个近端参考点的差值）时。
#   管外要拉到 +12 Å 才能看到真正的平台区；只取 ±5 Å 的话两端都还没进平台，
#   算出来的只是相对自由能差。
#
# ⚠️ 这个方案的已知脆弱点（用之前先确认）：
#   1. 混用了 k=250 与 k=10 两种弹簧。体相段靠"PMF 本来就平坦"才勉强成立；
#      若孔区附近的 PMF 有斜率，强/弱弹簧窗口之间会出现空 bin -> WHAM 输出 NaN。
#   2. 孔区 0.25 Å / k=250 的 σ=0.05 Å，中点偏置势差 0.5*250*0.125² = 1.95 kcal/mol
#      ≈ 3.3 kT，重叠其实比"均匀 0.4 Å + k=50"（1.7 kT）更差。
#   3. 最外侧 +12 与 +5 之间还隔着体相平坦区，窗口间距 1.0 Å 是可以的，
#      但**不要**把这种大间距照搬到势垒附近。
#   （默认的窄量程方案见同目录 windows.txt，那份更稳。）
#
# ⚠️ 无论用哪个方案，窗口清单里【必须】包含势垒中心那一个。
#    本方案含 0.00，没问题 —— 详见 windows.txt 顶部的实测教训。
#
# 本方案对应的建模与 SMD 参数：--zmax 12 --zmin -6；SMD 从 +12 拉到 -6。
