# US 窗口清单：每行 "窗口中心z 弹簧常数k"
#
# ============================================================
#  方案（默认，窄量程 ±5 Å 版）：均匀步长 0.4 Å + 孔心 0.00，共 27 个，全域 k=50
# ============================================================
#
# 为什么这样配：
#   10 Å 总范围摊到 26 个格点 -> 平均间距只有 0.4 Å。相邻窗口在中点处的偏置势差
#   = 0.5*k*Δz² = 0.5*50*0.2² = 1.0 kcal/mol ≈ 1.7 kT，直方图重叠充分。
#   k=50 对应涨落 σ=sqrt(RT/k)=0.11 Å —— 既能钉住离子，又足够宽到与邻窗重叠。
#
# 三条通用规则（换体系照这个来，不要照抄数字）：
#   ① **重叠判据**：相邻窗口中心的间距 Δz 应 ≲ σ = sqrt(RT/k)。
#      Δz 远大于 σ 时两个窗口直方图断开 -> WHAM 在缝里输出 NaN。
#   ② **混用弹簧可以，但每个接头都要验算重叠**（别一刀切"必须统一 k"）：
#      判据（与 check_setup_us.py 第 7 项一致）是相邻两窗 ±3σ 必须相交，
#      Δz ≤ 3(σ_i + σ_j)，σ = sqrt(RT/k)。但这只是**必要条件** ——
#      「强弹簧孔区窗 → 弱弹簧体相窗」那个接头最危险，要按实测直方图数一下
#      空隙区每 0.01 Å bin 还剩几个样本（≳5 才算稳）。
#      实测反例（CNT5，2026-10-10）：孔区 k=50(σ=0.11) 接体相 k=10(σ=0.245)、
#      间距 1.0 Å，±3σ 判据报"余量 6%、刚过"，但空隙区 [5.22,5.51] 每 bin 只剩
#      **1.6** 个样本 → 期望空 bin 数 ~0.5，约 40% 概率冒出 1 个 NaN
#      （会被 pmf/wham.py 的空洞守卫拦下，得加 --allow-holes 才过得去）。
#      改成 k=5(σ=0.346) + 间距 1.5 Å 后：最薄接头 9.4 样本/bin、风险归零，
#      而且 5 个窗口就覆盖 +6~+12（比 k=10/步长1.0 的 7 个更省）。
#      结论：宁可用更弱的弹簧配更大间距，也别让强窗边缘去够弱窗的长尾。
#   ③ **必须包含势垒中心窗口**（见下面 ⚠️）。
#
# ⚠️ 实测教训：窗口清单里【必须】有势垒中心那一个（本体系是 z=0.00）
# ---------------------------------------------------------------------------
#   本体系最初只取 0.4 Å 均匀格点，从 -5.0 起步，格点恰好是 ……-0.60, -0.20,
#   +0.20, +0.60……，把 0.00 跳了过去。当时判断"孔心由 ±0.20 两个窗口共同采样
#   （0.2/σ = 1.8σ），不用专门加"，**是错的**。26 个窗口跑完后实测：
#       窗口中心 -0.20 -> 离子实测均值 -0.429 (sd 0.095)，|z|<0.15 只采到  8 个样本
#       窗口中心 +0.20 -> 离子实测均值 +0.430 (sd 0.098)，|z|<0.15 只采到 13 个样本
#   离子被系统性推离孔心 0.23 Å，WHAM 在 z∈[-0.14,+0.11] 输出 26 个 NaN 空洞，
#   势垒高度只能靠两侧斜坡外推（17.0 是外推值，补窗口后实测 17.8）。
#   根因：势垒顶部又窄又陡，0.4 Å 网格在峰顶处包不住离子。
#   参考库最早的版本间距 0.25 Å、本来就含 0.00，所以它没这个问题 —— 改成
#   均匀 0.4 Å 时把这个窗口"优化"掉了，才暴露出来。
#   **结论：任何窗口清单，先确认势垒中心（通常是 z=0.00）在列表里。**
#
